# Leakage：radiationポスターに対応する再実験

## 結論

ReserveQ由来の検出イベント注入モデルでも、シンドロームから発生元のデータ量子ビット座標を推定できた。
通常条件の平均誤差は、適用版REI 2.695、SVR 1.843、Ridge 1.892、CNN 1.692。
空間情報の除去・位置対応の破壊で推定が定位置予測と同程度まで悪化した。
一方、配置を大きく／高密度にすれば必ず改善する、という結果ではなかった。

単位は以下すべて **nominal mm（仮定した座標スケール）**。
実機でmm単位の精度を達成したという意味ではない。radiationとの絶対誤差ランキングには使わない。

## 何を揃え、何を変えたか

| 項目 | 今回の設計 |
|---|---|
| 符号 | rotated surface-code Z-memory。主比較は d=5 |
| 回路雑音 | radiation主比較と同じ：ゲート0.0005、測定0.001、リセット0.001 |
| 主比較 | 適用版REI vs SVR、副比較Ridge/CNN、定位置予測を対照に追加 |
| 分割 | 各学習replicaで学習864・検証180イベント、共通の未使用テスト540イベント |
| 再現性 | 学習データと初期化seedを変えた3 replicas（41/42/43） |
| ショット | 1イベント2ショット。発生位置・開始round・注入確率を共有するが、推定は1ショットずつ |
| 入出力 | 検出イベントの空間×時間配列のみ → 連続座標(x,y)。真の位置・開始round・強度は入力しない |
| 通常観測 | 16-round prefixの内部15 round。初期・終端の不完全な検出層は除外 |
| 追加観測 | 同じ32-roundデータの4/16/32-round prefix。各条件で再学習 |
| 発生時刻 | 0/1/2 roundを一様抽出。未知だが早期に発生する設定であり、任意の時刻への汎化は未検証 |
| 発生位置 | 主比較は25個のデータ量子ビット座標。学習・テストは新しいイベントだが座標集合は共通 |
| leakage | graph transport=0.123/round、decay=7.63 round、persist=32 round |
| 強度層別 | corruption probability 0.15/0.30/0.50を弱/中/強proxyと呼ぶ。各テスト180イベント |
| 空間尺度 | 全量子ビットのbounding-box中心を引いたStim座標×pitch。主比較pitch=1、範囲[-5,5]² |

強度proxyはradiationのエネルギー・QP生成量ではない。leakageの実測強度分類でもない。
モデルは同一混合強度で学習し、真の強度によるモデル切替は行っていない。
データ量子ビット間隔は主比較で2 nominal mmであり、`pitch=1`をそのまま隣接データ量子ビット間隔1 mmとは呼ばない。

radiationの約4 ms/4095内部roundとは観測長が異なる。leakageの短い寿命を観測するround単位の比較である。
radiationの連続的な発生位置、外部発生、円／楕円形状、ballistic/diffusive分岐はそのまま移植していない。
leakageの発生元は量子ビットで、伝播は回路接続グラフ上で定義されるためである。
実測データとの時間・空間応答比較は実施していない。

## 1. モデル比較

| モデル | 全体 | 弱proxy | 中proxy | 強proxy | 1 nominal mm以内率（全体） |
|---|---:|---:|---:|---:|---:|
| 適用版REI | 2.695 | 3.697 | 2.534 | 1.856 | 20.5% |
| SVR | 1.843 | 2.525 | 1.784 | 1.220 | 33.1% |
| Ridge | 1.892 | 2.565 | 1.813 | 1.297 | 29.3% |
| CNN | 1.692 | 2.246 | 1.598 | 1.232 | 36.4% |
| 定位置（学習座標平均） | 3.877 | 3.957 | 3.768 | 3.905 | 3.5% |

SVRは適用版REIに対して平均誤差31.6%減、CNNは37.2%減。
対応イベントbootstrapによるSVR−REIの平均誤差差は−0.852、95%区間[−0.952, −0.755]。
3学習replicasの全体平均範囲はSVR 1.822–1.865、CNN 1.648–1.730。
CNNは全体・弱・中で最も低い平均誤差だったが、強proxyではSVRと近い。
この表の小さい差すべてを統計的優越性と主張するものではない。

REIはradiation主比較の`rei_rates`を直接使用：頻度閾値、空間相関フィルタ、min–max変換後の二乗重みを保持。
観測窓末尾の履歴長3/7/15を検証データで選択し、未回答時は学習座標平均へfallbackする。
通常条件の回答率は66.7%。未回答を除外して有利な事例だけを主比較に使ってはいない。
REIが回答した**同じショット集合**で比べても、REI 1.824、SVR 1.564、Ridge 1.627、CNN 1.549だった。
したがって全体差のすべてをfallbackだけで説明することはできない。
原著REIの完全再現や原著超えを示した実験ではない。

SVRは標準化＋RBF核のx/y別回帰。C={0.1,1,10}、gamma分子={0.057,0.57}を検証データで選択。
Ridgeはalpha={1,10,100,1000}から選択。
CNNは実際のcheck座標へ配置した2層2D畳み込み＋全結合回帰、時間層を入力channelとして扱う。
不在checkのmaskを付加し、60 epochから検証誤差最小のcheckpointを選ぶ。
入力変換・ネットワークはradiationのCNNと同一ではなく、短いleakage系列用の副比較である。
表は3 replicasの**誤差の平均**であり、予測座標を平均したensembleの精度ではない。

## 2. 特徴量比較（SVR）

| 条件 | 平均誤差 |
|---|---:|
| F0：Spatial + temporal | 1.843 |
| F1：Spatial only | 1.901 |
| F2：Temporal only | 3.878 |
| N1：Shuffled check positions | 3.875 |
| N2：Shuffled time order | 2.093 |

F0は独立quiet referenceを引いて負値を0にした観測を5時間binへ平均し、各binの空間平均+0.003で正規化する。
F1は時間を平均、F2は空間を平均する。N1/N2はイベントごとに独立に位置／時間順序を並べ替え、同じイベントの2ショットには同じ置換を使う。
各変換でモデルを再学習する。N1は全データ共通の学習可能な置換ではない。

空間情報が主要な手掛かり。時間順序の破壊でも悪化した（N2−F0=+0.249、95%区間[0.195,0.304]）。
F1−F0の区間は[−0.003,0.118]であり、今回の差だけでF0の優位が明確とはいえない。
特徴量次元・正則化も変わるため、差は情報だけの純粋な因果効果ではない。

## 3. 雑音・未知伝播への頑健性

| 条件 | 適用版REI | SVR | Ridge | CNN |
|---|---:|---:|---:|---:|
| 通常 | 2.695 | 1.843 | 1.892 | 1.692 |
| 回路雑音2倍 | 2.804 | 2.215 | 2.221 | 2.090 |
| 未学習の遅いtransport=0.03 | 2.555 | 1.657 | 1.719 | 1.561 |

通常条件で学習・選択したモデル、REI履歴長、quiet referenceを固定。再学習・テストでの調整なし。
発生位置・強度・時刻を対応付けた540テストイベントを使用。
低速条件で誤差はむしろ低下した。発生元近傍に情報が残ることと整合的だが、因果的に実証していない。
未知条件への一般的汎化ではなく、この1種類のtransport shiftでの結果である。

## 4. 配置・観測時間（SVR）

| 実験 | 条件 | 平均誤差 |
|---|---|---:|
| 間隔固定・観測範囲拡大 | d=3 / 5 / 7 | 1.121 / 0.974 / 1.092 |
| 面積固定・高密度化 | d=5, pitch=1 / d=15, pitch=1/3 | 1.843 / 2.758 |
| 観測延長 | 4 / 16 / 32 round prefix | 2.145 / 1.843 / 1.788 |

観測範囲実験は全dで同じ9発生座標[-2,0,2]²を使う。
主比較の25座標とは難易度が異なるため、0.974と主比較1.843を直接ランキングしてはいけない。
d=5→7の悪化は+0.118（95%区間[0.070,0.166]）。広範囲ほどよいとはいえない。

密度実験は全量子ビットの10×10 nominal mm範囲と25発生座標を厳密に固定。
d=15を選んだのはd=5の全発生座標が高密度側の量子ビット上にも正確に存在するため。
チェック数24→224、特徴量数120→1120に対し、学習量は864イベント/replicaで固定した。
15内部roundの背景検出数期待値は3.17→32.88、観測数からquiet期待値を引いた増分は4.89→6.49。
背景・次元の増加に対して信号の増加は小さい、という観測であり、悪化原因の単独確定ではない。
同じtransport/roundを使うのでpitch変更で物理距離あたりの広がりも変わる。
**物理的な伝播長を固定した純粋なセンサ密度効果、あるいは全モデルでの高密度化の限界とは主張できない。**

観測延長は16→32 roundで−0.055（95%区間[−0.098,−0.013]）と小幅改善。
同じイベントと開始時刻を使い、4 round側も32-round回路の内部prefixとして切り出した。
時間bin境界と学習済みモデルも変わるので、追加時間だけの効果から完全に分離はしていない。

## 評価と研究上の範囲

- 主指標は1ショットごとの座標ユークリッド誤差。平均、中央値、90%点、1以内率、4超率を保存。
- CIはショットとreplicasをイベント内で平均し、540イベントを単位に2000回bootstrapしたもの。
- CIはこの3学習replicasに条件付けたテストイベントの不確かさ。一般の学習seed変動を完全に含む区間ではない。
- 多数の探索的比較で、多重比較補正した確認的検定ではない。
- テストは未使用イベントだが発生座標と生成パラメータの候補は学習と共通。未知位置・未知回路・別注入機構への汎化は未証明。
- イベント存在を前提とした局在化。no-event判定、複数発生源、ancilla発生源、BB code、復号効果は未評価。
- leakageは検出イベントの確率的置換モデル。qutrit回路での漏れ・回復を直接シミュレートしていない。
- 以前の単純centroidをREIと呼んだ結果や、不正確なreshapeのCNN/GNN結果はここには混ぜていない。
