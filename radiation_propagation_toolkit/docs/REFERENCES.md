# Model references

- Yelton et al., *Modeling phonon-mediated quasiparticle poisoning in superconducting
  qubit arrays*, [arXiv:2402.15471](https://arxiv.org/abs/2402.15471): QP rate equation
  and QP-induced transmon relaxation relation used by the ODE backend.
- McEwen et al., *Resolving catastrophic error bursts from cosmic rays in large arrays
  of superconducting qubits*,
  [Nature Physics DOI](https://doi.org/10.1038/s41567-021-01432-8),
  [arXiv:2104.05219](https://arxiv.org/abs/2104.05219): Google RReCS event data used
  for the measured-hardware comparison documented in `VALIDATION.md`.
- Baity et al., [arXiv:2602.06202](https://arxiv.org/abs/2602.06202): reference
  T1/T2-to-Pauli QEC pipeline, representative gate times, and QP dephasing relation.
- Kurilovich et al., [arXiv:2506.18228](https://arxiv.org/abs/2506.18228): motivation
  for the optional QP-dependent phase/frequency-shift branch.

The bundled numerical values are priors and engineering reference settings. Citing a
paper does not make those values calibrated to a particular target processor.
