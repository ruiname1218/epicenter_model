2026-09-12に内容を精査して日英とも改訂：[精査・修正記録](REVIEW_JA.md)。

## 採用した結果

1. [同一観測時間・新規テストの適用版REI比較](../rei_fair_20260911/RESULT_JA.md)：主結果と条件別分析。
2. [同一記録の観測時間比較](../long_observation_20260910/RESULT_JA.md)：補助的な要因分析。
3. [特徴表現とカーネル幅の対照](../feature_selection_20260910/RESULT_JA.md)：探索的な要因分析。

グラフは各実験のCSVから直接作成。異なる実験の数値を共通ランキングにしません。
平均位置誤差は推定座標と真の座標のユークリッド距離（mm）。
同じ物理イベントに属する2ショットを独立イベントとして数えていません。
主比較は全強度を均等に含み、通常テストの各強度は180イベントです。
最新CNNは3初期化seedの座標平均アンサンブルであり、3つの独立学習集合ではありません。
資料の主比較以外の強度・形状・汎化解析は探索的です。
モデル構造・全パラメータ・信頼区間の算出方法は元レポートを参照してください。

## 再生成

リポジトリ `radiation_propagation_toolkit` 内で実行：

```bash
.venv/bin/python examples/build_paper_summary.py
```

`sources.json` に入力データ・元レポートのSHA-256を保存しています。
`ja_page_*.png` / `en_page_*.png` はページ確認用のプレビューです。
PDF内の図・テキストはラスタ画像ではなく、拡大可能なベクトル出力です。
