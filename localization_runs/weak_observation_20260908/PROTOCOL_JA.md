# 弱イベントの観測時間・時刻統合・物理照合（テスト前計画）

目的は、弱イベントで学習数だけを増やしても改善しなかった原因を、観測条件と推定手法の両面から調べること。今回は **低強度帯だけの条件付き診断**であり、強度が不明な全イベント分布での性能や、無イベント検出の実証ではない。

## 対応付きデータ

新規 720 個の物理イベントを生成する。形状 2 × 伝播則 2 × 発生位置領域 3 の 12 層、各 60 個。低強度の生成スケールは従来の [1e-10, 1e-9] /us。各層を固定乱数で学習 36・検証 12・テスト 12 に分け、総数 432 / 144 / 144 とする。物理 seed=20270220、シンドローム seed=20270221、device_seed=123。開発用 pilot の物理 seed=20270210 とは分離する。

各イベントの QP/T1/T2 履歴は一度だけ計算し、次の 2 条件で Stim の測定記録・detector events を生成する。各 2 shots。

- nominal: 既存の通常ハードウェア・回路ノイズ。
- quiet10: ベースライン 1/T1・1/T2 と、残余 Clifford・測定・リセットの故障確率を 0.1 倍。放射線による緩和・脱位相率の増分は保持する。

quiet10 は仮想的なハードウェア改善条件であり、観測後のデノイズ処理ではない。異なるノイズ条件では乱数ストリームを分離する。両条件の同じ物理イベントを対応させ、shots は独立イベント数に数えない。

8.192 ms（8,192 rounds）の取得から 2.048 / 4.096 / 8.192 ms の内部 detector events を切り出す。短い窓の予測には未来のビットを渡さない。符号・配置は固定 distance-3 surface code のまま。

## 方法

各条件 × 各窓の計 6 ケースで、同じ学習イベント集合を使う。

1. 固定 345 round 区切りの 57 特徴: Ridge、SVR、ExtraTrees 3 seed 座標平均、SVR/ExtraTrees 50:50。
2. 発生時刻統合: 学習時は教師ラベルの発生時刻で区切った特徴を使う Ridge/SVR。推論時は 50〜650 rounds の 7 候補を計算し、一様重みまたは観測された変化のスコアによる重みで座標を統合する。テストの真の発生時刻は使わない。重みは較正済み時刻事後確率ではない。
3. 物理照合: 学習イベントの物理パラメータ仮説ごとに、categorical Pauli チャネルから detector の周辺発生確率を計算する。32 round ごとにビン化し、観測カウントとの composite likelihood で仮説を重み付けする。位置・強度・形状・速度・発生時刻などは、学習イベントの有限 Monte Carlo 仮説集合を通して統合する。位置平均／幾何中央値、逆温度 0 / .03 / .1 / .3 / 1 / 3 を比較する。
4. 位置ラベルの幾何中央値だけを返す prior。

物理照合は経験的な少数ショットの近傍照合とは異なるが、厳密な結合物理尤度ではない。最終的な周辺確率は各独立ノイズ位置の categorical Pauli 確率から計算し、近似 DEM や回路表示文字列の丸めは用いない。ただし推定スコアには、時間ビン内の確率平均、チェック・時間の独立性仮定（または Gaussian GLS 近似）が残る。全シンドローム相関や輸送 PDE を解いてはいない。逆温度 0 は情報を使わない対照である。

推論入力は観測された detector events と学習済み成果物のみ。物理確率配列は学習イベントにしか保存しない。検証・テストの物理状態を正解テンプレートとして渡す oracle 推定はしない。

## 選択・評価

計 33 候補 × 6 ケース。各ケースの検証平均 Euclidean 位置誤差で、全体最良（prior を含む）、固定方式最良、時刻統合最良、物理照合最良を選ぶ。通常ノイズで使う窓も検証だけで選ぶ。全モデル・選択・ハッシュをテスト前に凍結し、テスト順位で選び直さない。

学習・評価前の追加候補として、物理照合に Gaussian GLS スコアも加えた。学習シンドロームのビン内カウントと物理期待値との差から、8 checks 間の 8×8 共分散を求め、非対角成分を 10% 縮小して使用する。時刻間の全相関や非 Gaussian 性まで扱う尤度ではない。平均／幾何中央値と同じ 6 逆温度で 12 候補を追加し、上記合計 33 とした。

テスト 144 イベントで平均・中央値・90 パーセンタイルの位置誤差 mm を報告する。窓変更・背景変更・方式変更・prior 比較は対応付きイベント bootstrap 10,000 回で差の 95% CI を出す。多重性補正、学習集合の再抽出に伴う変動、実機への保証は含まない。弱い例だけで検証選択する探索的診断である。

## 実行上の変更

生成を高速化するため、同じ時間幅の Pauli チャネル計算をバッチ化し、Stim への回路命令追加を全精度テキストでまとめた。スカラー計算との完全一致、元の命令追加方式との回路一致、同一乱数の測定一致を単体テストした。生成途中の完了 26 イベントは保存し、途中のイベントだけを再計算して継続した。旧・新のソースハッシュは protocol.json の履歴に保存する。

さらに、DEM の小さい target 集合を NumPy で毎回ソートする部分を同じ XOR 集計に置換した。元の周辺確率との完全一致を単体テストし、別の開発用 512 round・2 ノイズ条件で保存される全配列が変更前と完全一致することを確認した。その変更の導入でも完了イベントを保全して再開した。開発用 event=999 は本実験の 0〜719 に含めない。

その後、学習・評価前に、固定 Clifford 回路の Pauli fault response を再利用する生成方式へ切り替えた。X/Z の伝播は Stim の単一 fault probe で求め、Y は X と Z の XOR として扱う。ノイズ位置ごとの I/X/Y/Z を排他的にサンプルするため、独立 detector をサンプルする近似ではない。残余回路ノイズは元の Stim 回路から独立にサンプルして XOR 合成する。対象は d3 rotated memory-Z の内部 detector events だけで、一般の非 Clifford 回路や非 Pauli 雑音への主張ではない。

検証: 起動直後・通常・最終 round の応答照合、64 個の強制 multi-fault ケースで元 Stim 回路との完全一致、20,000 shots で周辺率とランダムな 5 detector のパリティの一致、同一 seed の再現性。新方式は同じノイズ分布を生成するが乱数の消費方法は変わるため、旧方式と同じ seed の新規ビット列の一致までは主張しない。切替前のシンドロームは保全し、全学習テンプレートだけを厳密な周辺確率で再計算する。書き換え前の学習ファイルは legacy_files/ に保存する。旧テンプレートには小さい disjoint-channel 近似誤差があったが、最終学習には用いない。
