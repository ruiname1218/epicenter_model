# 新規確認評価前の固定方針

2026-09-08 JST、新規データ生成中に作成。新規テストの予測・誤差は未計算。

学習は旧window_calibrationデータの360イベント、検証120イベント、各2ショット。
通常4種類のCNNの再探索ではなく、保存済みoriginal CNN seed 41/42/43を固定して利用。
単体seed 41と、3モデルの予測座標平均（アンサンブル）を別の基準にする。
以前の3seedの「誤差平均」と今回の「座標平均アンサンブル」は異なるため区別する。

33候補を検証平均位置誤差で比較した。通常候補25、oracle診断8。

- 現行単体、現行アンサンブル、学習座標平均の3基準。
- 観測された全期間平均発火率と独立平常時較正の差による、6種類の縮小処理。
- 固定時刻/観測変化点/真の発生時刻の3区切り方。
- 各区切り方で、Ridge正則化3候補、ExtraTrees最小leaf 2候補、見本照合の近傍数3候補。

選択された通常モデルは **fixed_ridge_100.0**。
検証平均位置誤差は2.851916 mm、現行単体2.897161 mm、アンサンブル2.883339 mm。
真の発生時刻を使うoracle候補を選択対象に含めていない。
新しいテスト結果を見てモデルを選び直さない。

全区切り方は同じ特徴表現・学習/検証集合を使う。特にRidge alpha=100の3条件を
対応付けて比較し、モデル容量の違いを区切り方の効果と混同しない。
固定時刻は学習イベントの発生時刻中央値で、推論対象の正解時刻ではない。
観測変化点は全チェック平均の上昇を使うオフライン推定で、物理的発生時刻とは異なる。

パターン照合は学習イベントの2ショットの特徴を平均した経験的見本に対する近傍回帰。
物理伝播モデルの尤度や粒子輸送を逆算したものではない。
縮小処理の係数も、校正済み信頼確率ではなく観測強度に基づくヒューリスティック。

新規360イベント・各2ショットはすべてテスト専用。
