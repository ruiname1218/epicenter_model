# データ増加実験・生成中に固定する方針

学習数360/720/1440/1800の第1段階。5760件は今回は未実施。
同じ回路・固定デバイスの既存2160独立イベントを学習候補へ移す。
旧検証・旧テストを含むことを明示し、それらを今回の性能評価には使わない。
強い楕円の360イベントを学習から除き、通常30区分の各60イベントを候補とする。
区分は形状×伝播則×位置領域×強度。各サイズは区分内で入れ子にする。

新しい720イベントをseed20261120、syndrome_seed20261121、device_seed123で生成。
各36区分20イベントを固定seed90502で10/10に分け、新規検証360・新規テスト360を作る。
検証は通常300イベントのみをepoch・モデル選択に使用し、強い楕円60例は選択に使わない。
テストは通常300・強い楕円60。全モデルを固定するまでテスト予測・誤差を計算しない。

Ridge(alpha100)、SVR(C10,gamma.001,epsilon.1)、元の時間CNN＋GNNを比較。
Ridge/SVRは既存の57特徴と独立平常較正、固定時刻区切りを継承。
GNNは生の2047内部ラウンドと配置・X/Z種別を入力する。
ハイパーパラメータを学習数ごとに探索し直さない。
GNNはseed41/42/43、最大40epoch、patience8、AdamW lr.001、batch64。
対照の学習数360でも今回は旧モデルではなく新しい入れ子集合から再学習する。
GNNは3seed単体誤差の平均で、座標アンサンブルではない。

同じ新規テストで学習数ごとの平均、中央値、p90、強度別誤差を評価。
同じモデルの360イベント学習との差をイベント単位bootstrapで報告する。
区間は記述的で多重性調整・学習集合の再抽出変動を含まない。
新規検証平均でモデルと学習数を選び、その選択も採点前に保存する。
旧実験で方法を探索済みである点、新規データも同じ合成物理モデルである点は残る。
