# 公開用リポジトリの読み方

`main` は、論文で扱う候補を整理した「結果公開用」のブランチです。
全実験を一つの順位表にせず、比較条件が一致する結果だけを同じ図にしています。

1. [日本語PDF](../paper/research_summary_ja.pdf) または [英語PDF](../paper/research_summary_en.pdf) を読む。
2. 詳細を確認する場合は `results/` の各 `RESULT_JA.md` を読む。
3. `metrics.csv` が集計値、`predictions.csv` が保存済みショット別予測です。
4. `protocol.json`・`selection.json` などは生成・選択条件、`audit.json` は保存時の検査記録です。

過去の探索コード・結果は `experiments/snapshot-20260912` に保存しています。
現在の主比較の生成・学習・評価には[再現実行ガイド](../../reproducibility/README.md)を使います。
固定commitのコードと公開済み設定を取得する方式で、過去のローカル実験フォルダは不要です。
仮想環境、キャッシュ、既存リポジトリ内部の `.git`、秘密情報は公開対象にしません。
大容量データの保存方針は実験ブランチのREADMEを確認してください。

## 注意

- 主比較：通常条件、約4 ms、全強度平均のSVR対適用版REI。
- 強度別・形状別・未知条件の比較は探索的。
- 学習教師は座標のみですが、SVR/Ridgeの平常較正など、REIと学習条件まで同一ではありません。
- 原著REIの完全再現、実機への汎化、イベント検出や復号性能の改善は未実証。
- 主比較には新しい再学習用コマンドがありますが、全補助実験の再学習までは対応していません。
- 独立学習集合での追試・先行研究との新規性確認・完全なMethodsは論文化に残る作業です。

再生成手順は[トップページ](../README.md)と[再現性文書](REPRODUCIBILITY.md)に記載しています。
