棒は各条件の平均ユークリッド位置誤差。点線は同じテストでの適用版REIです。F0は主比較SVRの相対空間分布5窓入力です。F1は空間分布を時間平均した「空間のみ」、F2は全チェックを平均してチェック位置を消した「空間なし（時間のみ）」です。F3は全体正規化レベル、F4は各チェックの時間平均を除去、F5/F6は前半／後半窓、N1/N2はチェック／時間順のシャッフルです。全条件は120入力に揃え、主SVRの C=1, epsilon=0.1, gamma=0.57/120 を固定しました。
